一键部署到 GitHub Pages 并在手机上畅玩

无需服务器、完全免费，自动获得手机摄像头所需的 HTTPS 安全链接

第一步 · 获取完整单文件源码 所有 AI 手势与合成器代码已打包在单个文件中

点击下方按钮即可直接将当前应用保存为标准的 index.html 文件：

第二步 · 3 步上传到您的 GitHub 并生成手机网址
1 新建公开仓库

登录 github.com/new，输入仓库名（例如 finger-music），选择 Public 并点击 Create repository。

2 上传 index.html

点击仓库里的 uploading an existing file，把刚才下载的 index.html 拖进去，点击底部绿色的 Commit changes。

3 开启 GitHub Pages

进入仓库顶部 Settings ➔ Pages，在 Branch 下拉框选择 main 并点击 Save。等待1分钟即可生成专属网址！

为什么推荐 GitHub Pages？ 手机浏览器（iOS Safari / 微信 / Chrome）出于安全规范，要求网页必须是 https:// 协议才允许调用摄像头。GitHub Pages 会免费自动为您配置好 HTTPS（网址形如 https://您的用户名.github.io/finger-music/）。
第三步 · 把网页添加到手机桌面（像原生 App 一样全屏运行）
iPhone / iPad (Safari)

用 Safari 打开您的 GitHub Pages 网址，点击底部中间的「分享 」按钮 ➔ 选择 「添加到主屏幕」。

Android (Chrome / Edge)

用浏览器打开您的网址，点击右上角菜单「⋮」➔ 选择 「添加到主屏幕 / 安装应用」 即可全屏运行。

手机与电脑竖指识谱指南

📱 单手高低区模式（默认开启，最适合一只手拿手机）：

  • 手掌在画面下半区：伸出 1~5 根手指对应 1 (Do)、2 (Re)、3 (Mi)、4 (Fa)、5 (Sol)。
  • 把同一只手举高越过画面粉色虚线：伸出 1、2、3 根手指自动升为 6 (La)、7 (Si)、1̇ (高音Do)！
  • 握拳 (0 指)：立即停止发声（休止符）。

🙌 双手 1~10 指数量模式（适合把手机立在桌面上或用电脑）：

  • 单手 1~5 指对应 Do ~ Sol；双手配合伸出 6~10 指对应 La、Si、高音Do、高音Re、高音Mi。

🎹 手机触控滑音：

在手机屏幕上按住彩色音符卡片并左右滑动手指，即可像弹奏古筝/钢琴一样连续滑音演奏！
